# Travel Kin - Wander Together, Safely 🏖️

**Travel Kin** is a Southeast Asia-focused social travel companion designed for modern explorers. It connects users with verified travel crew, expert guides, and curated experiences in paradise.

## 🌟 Core Mission
To transform travel from a lonely transit to a shared adventure by building the most trusted social layer for Southeast Asian exploration.

## 🎨 Design System: "Golden-hour Editorial"
Inspired by the calm, premium aesthetics of Apple’s product interfaces, but infused with the vibrancy of the tropics.

- **Palette**: Sand (#F5F0E1), Ocean (#0077B6), Sunset (#FF8C42), and Slate (#2F3E46).
- **Typography**: Inter for crisp UI readability; Playfair Display for editorial elegance.
- **Visuals**: Glassmorphism navigation, smooth fluid animations, and high-fidelity beach photography.

## 🏗️ Technical Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: TailwindCSS
- **Type Safety**: TypeScript
- **State**: Server Components & Modern React Hooks

## 🚀 Features
- **AI Travel Kin (Intelligence)**: Context-aware chat with travel companions powered by the Pollinations/Gemini engine.
- **Kin Radar Scan (Spatial Discovery)**: Real-time discovery of nearby explorers within a 5km radius using high-fidelity tactical animations.
- **SOS Emergency Ring (Safety)**: Global broadcast system with hold-to-alert functionality to notify local responders and your trusted circle.
- **Passport Verification (Trust)**: Biometric ID verification terminal that grants the 'Verified' badge to users.
- **Interactive Itineraries**: Social upvoting and task management for shared travel plans.
- **PWA Mobile Native**: Full Progressive Web App support with offline persistence and home-screen installation.
